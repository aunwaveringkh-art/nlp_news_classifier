# Классификация новостей на русском языке

Проект по мультиклассовой классификации текстовых новостей на 11 тематик **без использования трансформеров**. Реализован полный пайплайн классических методов NLP: TF-IDF (word + char), TruncatedSVD, линейные модели, специализированный классификатор и взвешенный ансамбль.

## Постановка задачи

**Тип:** мультиклассовая классификация (11 взаимоисключающих классов).

**Метрики:**

- **Accuracy** — основная, дисбаланс умеренный
- **Macro-F1** — чувствительна к слабым классам
- **Weighted-F1** — взвешена по количеству примеров

**Ограничение:** запрещено использовать трансформеры (BERT и наследники). Работаем только с классическими методами.

**Критерии оценки:**

| Критерий | Баллы |

| Корректная предобработка | 5 |
| Классификация ≥ 90% | 10 |

| Обработка данных после классификации | 10 |
| Обоснование выбора метода | 5 |

## История работы: от бейзлайна до финала

Мы прошли **четыре итерации**, каждая из которых давала прирост.

### Итерация 1: Бейзлайн на простом TF-IDF

**Что делали:** TF-IDF по словам (1,2), `max_features=30000`, Logistic Regression и LinearSVC.

**Результат:** Test Accuracy = **0.8550**

**Что узнали:** SVM обгоняет LogReg на 1%. Проблема — `society` (F1 = 0.66), `politics` (0.78), `conflicts` (0.79). 90% ошибок — на пересечении этой тройки.

### Итерация 2: Расширенная векторизация

**Что делали:** n-граммы (1,3), `max_features=80000`, добавили символьные n-граммы (3,5) через `char_wb`.

**Результат:** Test Accuracy = **0.8647** (+0.97%)

**Что узнали:** символьные n-граммы работают для русского. Ансамбль через усреднение почти равен SVM.

### Итерация 3: SVD + ComplementNB + ансамбль

**Что делали:** добавили TruncatedSVD (400 компонент), LogReg на SVD, ComplementNB, random search для весов.

**Результат:** Test Accuracy = **0.8646** (не улучшилось)

**Что узнали:** random search обнулил веса слабых моделей — ансамбль превратился в чистый SVM.

### Итерация 4: Специалист + softmax-веса (финальная)

**Что делали:**

1. Специализированный SVM для `{society, politics, conflicts}` — учится только на этих трёх классах
2. Заменили random search на softmax от accuracy валидации

**Результат:** Test Accuracy = **0.8659** (+1.09% над бейзлайном)

**Почему остановились:** дальнейший рост возможен только через fastText (+0.5–1.5%) или BERT (запрещён). Мы достигли потолка линейных методов.

## Финальный пайплайн

**Шаг 1. Векторизация.**
Текст → Очистка (lowercase, regex) → TF-IDF по словам (1,3) + TF-IDF по символам (3,5) → объединение через `scipy.sparse.hstack` → разреженная матрица (130k признаков).

**Шаг 2. Понижение размерности.**
TruncatedSVD (400 компонент) на объединённой матрице → плотная матрица (400 признаков).

**Шаг 3. Обучение моделей.**
На разреженных признаках:
- Logistic Regression (saga, C=0.5)
- Calibrated LinearSVC (C=0.5)
- ComplementNB (alpha=0.3)

На плотных SVD-признаках:
- Logistic Regression (lbfgs, C=1.0)

Дополнительно:
- Специализированный SVM для `{society, politics, conflicts}`

**Шаг 4. Ансамбль.**
Взвешенное голосование 4 моделей с весами `softmax(val_accs * 10)`.

**Шаг 5. Гибридное правило.**
Если базовая модель предсказала один из трёх классов и специалист уверен (>0.5) — берём ответ специалиста.

**Шаг 6. Финальное предсказание.**

### Ключевые компоненты

1. **Векторизация:** слова (1,3) + символы (3,5) → 130 000 разреженных признаков

4. **Специалист:** отдельный SVM для тройки `{society, politics, conflicts}`
5. **Ансамбль:** softmax от accuracy на валидации
6. **Гибридное правило:** специалист перебивает базовую модель, если уверен

## Обоснование выбора методов

### Векторизация

**Почему word (1,3):** униграммы — база для Bag-of-Words, биграммы ловят устойчивые словосочетания, триграммы добавляют фразовую информацию.

**Почему char_wb (3,5):** устойчивы к опечаткам, устойчивы к морфологии русского, критичны для языков с богатой морфологией (Аллаяров, слайд 18). Sublinear tf (1 + log tf) сглаживает частые слова.

**Почему TruncatedSVD:** даёт плотное представление, улавливает латентные семантические связи, 400 компонент — компромисс между потерей информации и скоростью.

### Модели

**LinearSVC:** исторически лучший метод для текста на разреженных признаках (Joachims, 1998). Hinge loss + максимизация зазора. Быстро обучается.

**Logistic Regression:** log-loss — даёт калиброванные вероятности. Устойчив на малых данных. Разные ошибки с SVM → база для ансамбля.

**ComplementNB:** генеративная модель (Аллаяров, слайд 26). Хорошо работает с дисбалансом. Даёт другую точку зрения.

**LogReg на SVD:** работает в плотном семантическом пространстве, дополняет LogReg на TF-IDF.

### Специализированный SVM

**Идея:** 90% ошибок приходится на три класса — `society`, `politics`, `conflicts`. Они семантически пересекаются.

**Решение:** отдельный SVM только на этих трёх классах. Гибридное правило: если базовая модель предсказала один из трёх и специалист уверен (>0.5) — берём его ответ.

**Результат:** Macro-F1 на тройке вырос с 0.79 до 0.81.

### Ансамбль

**Тип:** разнородный (heterogeneous).

| Модель | Loss | Признаки |
|--------|------|----------|
| LogReg sparse | log-loss | sparse TF-IDF |
| Calibrated SVM | hinge-loss | sparse TF-IDF |
| ComplementNB | generative | sparse TF-IDF |
| LogReg SVD | log-loss | dense SVD |

**Веса:** `softmax(val_accs * 10)` — все веса ненулевые. Это гарантирует реальный ансамбль.

## Анализ ошибок

### Топ-10 самых частых ошибок

| Истинный класс | Предсказано | Кол-во |
|----------------|-------------|--------|
| society | conflicts | 91 |
| politics | conflicts | 87 |
| conflicts | politics | 77 |
| society | politics | 69 |
| science | health | 60 |
| conflicts | society | 43 |
| politics | society | 43 |
| society | health | 41 |
| society | economy | 39 |
| gloss | economy | 35 |

### Причины ошибок

**1. Семантическое пересечение society / politics / conflicts**

> «Граждане вышли на протест против решения правительства. Полиция задержала 15 человек.»

Это **одновременно** society, politics и conflicts. TF-IDF не различает контекст.

**2. Science → Health**

> «Учёные обнаружили белок, связанный с болезнью Альцгеймера.»

Наука или здоровье? Модель видит оба набора ключевых слов.

**3. Gloss → Politics**

> «Ксения Собчак критиковала политику правительства на светском мероприятии.»

Gloss (светская хроника), но модель видит «политика», «правительство».

**4. Society → Economy**

> «Рост цен вынудил пенсионеров экономить на лекарствах.»

Society, но модель видит «цены», «экономить» → economy.

### Матрица ошибок

`results/confusion_matrix_final.png`:

- Диагональ ярко-синяя — большинство верны
- Пятна между society/politics/conflicts — систематическая путаница
- Sports и travel — почти идеальные

## Ограничения и потолок

### Что не пробовали

| Метод | Прирост | Причина отказа |
|-------|---------|----------------|
| fastText-эмбеддинги | +0.5–1.5% | Требует 4 ГБ, +30 мин, потолок ~88% |
| Стекинг (мета-LogReg) | +0.0% | Переобучение на валидации |
| BERT | +5–8% | Запрещён заданием |

### Реальный потолок

**86.6%** — близко к потолку линейных методов на TF-IDF. Причины:

1. Семантическое пересечение тройки — 25% теста
2. TF-IDF не моделирует порядок слов
3. Нет предобученных эмбеддингов
4. Нет контекста

### Проверка переобучения

- Val Accuracy: 0.8689
- Test Accuracy: 0.8659
- **Разница: 0.003** — минимальная

Модель обобщает, а не запоминает.
